# Speech-cortical-tracking-in-DLD-and-TLD

This repository contains the scripts and stimuli for the continuous speech
experiment and mTRF analysis.

## Repository contents

- [`scripts/`](scripts/): experiment and analysis scripts.
- [`stimuli/`](stimuli/): materials used in the experiment.

See the README in each directory for guidance on adding files. Only include
materials that may be redistributed, and do not commit participant recordings
or other identifiable data.
